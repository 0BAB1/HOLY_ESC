

# HOLY ESC

My effort to bring an open source, closed loop ESC to life.

From hardware to firmware.

You'll find the firwares in `./software` and the hardware kicad projects in `./hardware`

# REV A

Rev A consists in an ATMEGA328p based ESC.

But given the poor atmega performances and high mosfets prices in this build, I figured I would work on a REV B that would embed a STM32 for better perfs and more open source support for inspiration, But also cheaper and more available mosfets.
